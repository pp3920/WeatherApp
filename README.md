
Main Entry (main.jsx & App.jsx): This is the "brain" of the app. It brings all the pieces together.

Custom Hook (useWeather.js): Think of this as the "engine." It handles all the heavy lifting—talking to the API, managing loading spinners, and catching errors. It keeps our UI components clean.

Components (SearchBar & WeatherDisplay): These are the "face" of the app.

SearchBar sends the city name up to the engine.

WeatherDisplay takes the data and shows it to the user.
